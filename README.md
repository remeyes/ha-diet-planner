# Diet Planner – dodatek do Home Assistant

Tygodniowy jadłospis dla domowników: plan dzień po dniu z porcjami dla każdej osoby, lista zakupów
z odhaczaniem, baza przepisów z makroskładnikami, meal prep na cały tydzień i agenci AI (Claude API).

## Instalacja

[![Dodaj repozytorium do Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https://github.com/remeyes/ha-diet-planner)

albo ręcznie: **Ustawienia → Aplikacje → Zainstaluj aplikację → ⋮ → Repozytoria** i wklej:

```
https://github.com/remeyes/ha-diet-planner
```

Szczegóły: [diet_planner/DOCS.md](diet_planner/DOCS.md).

## Prywatność

Repozytorium zawiera wyłącznie kod i ogólne dane startowe (szablony profili, podstawowe przepisy).
Twoje profile, plany, przepisy i klucz API zostają na Twoim serwerze Home Assistant.
